**RecruitAI** is a futuristic, AI-driven recruitment platform designed to eliminate human bias and streamline the hiring process. This project was developed as a **Final Year Project (FYP)**, focusing on an immersive user experience and high-security standards.

---

## 🌌 Project Overview

RecruitAI bridges the gap between candidates and recruiters using a high-end terminal-style interface. The system doesn't just scan resumes; it calibrates with the candidate's neural and vocal patterns to ensure an authentic and high-quality interview experience.

### 🔄 The 0-100% Workflow
1.  **Auth Protocol:** Secure login/signup with a futuristic "Quantum Core" visualizer.
2.  **Job Discovery:** A clean dashboard to browse and apply for listed positions.
3.  **Resume Intelligence:** Upload and AI-based analysis of candidate CVs.
4.  **RecruitLink Calibration:** A WhatsApp-style "Hold-to-Talk" voice sampling system to sync microphone quality.
5.  **AI Interview Room:** Real-time, dynamic questioning powered by AI logic (Frontend Simulation).
6.  **Neural Insights:** A comprehensive 0-100% Match Score report based on technical and behavioral performance.

---

## ✨ Key Features

### 🎙️ RecruitLink (Voice Calibration)
- **WhatsApp Style UX:** "Push-to-Talk" functionality where users hold the mic to record.
- **Real-time Feedback:** Live waveform animations and frequency bars that react to voice input.
- **Noise Analysis:** Displays latency (ms) and gain (dB) to ensure a quiet environment.

### 🛡️ Cyber-Security & Hardening
- **Anti-Injection:** Input sanitization to prevent **SQL Injection** and **XSS Attacks**.
- **Secure Data Handling:** Client-side validation for all forms and file uploads.
- **Encrypted Feel:** Visual cues like "Security Keys" and "Neural Links" to instill user trust.

### 🎨 Premium GUI (Visual Identity)
- **Glassmorphism:** Modern blurred backgrounds with neon-glow borders.
- **Quantum Core:** A 3D-rotating CSS animation representing the AI engine.
- **Responsive Layout:** Optimized for a seamless "No-Scroll" full-screen experience.
